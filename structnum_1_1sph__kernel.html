Detailed Description

template<int Dim>
struct num::sph_kernel< Dim >

Smoothed Particle Hydrodynamics (SPH) smoothing kernel and gradient evaluations in 2D / 3D.

Implements standard Monaghan cubic spline kernel \(W(r, h)\) and Desbrun Spiky pressure kernel gradients. Compact support is strictly within \(r \in [0, 2h]\).

Template Parameters
DimSpatial dimension (2 or 3).
