Detailed Description

template<class Mat, class Ax>
class num::linear::structured_mat< Mat, Ax >

A stored matrix carrying an asserted axiom.

The matrix and operator sides of the library now record properties in one vocabulary: this and num::operators::structured_op place their argument at the same position in the num::property lattice. A self-adjoint matrix is square by construction, so no separate shape tag is needed here.
