# Concept Index {#page_concept_index}

Every concept `numerics` defines, grouped by what it describes. The distinction between
structure and law, how a type declares what it satisfies, and what the compiler says when
it does not are on the @ref page_concepts "concepts reference" page.

There are 83 of them. A concept is either a **structural** requirement the compiler
decides, a **law** the caller asserts and a runtime probe samples, or a conjunction of the
two. Every one refines another, and `ConceptHierarchy` in the test suite fails the build if
that stops being true.
