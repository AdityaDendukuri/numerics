# num::kernel Index {#page_kernel_index}

Every routine in `num::kernel`, the library's raw compute tier. It operates on pointers and
lengths, allocates nothing, and depends on nothing outside the standard library, so it can
be lifted out of this project and used on its own.

The contract every routine assumes, parameter tables for the common entry points, the
summation-order guarantee, and instructions for vendoring the tier are on the
@ref page_kernel "kernel reference" page.

All 88 are templates on the scalar type, take raw pointers and lengths, allocate nothing,
and are `noexcept`. **Nothing is checked** &mdash; read @ref page_kernel "the contract"
before calling any of them.
