35/// @brief Compute full symmetric eigendecomposition \f$A = V \Lambda V^T\f$.
36///
37/// Uses cyclic Jacobi plane rotations (in-tree fallback) or LAPACK divide-and-conquer (`dsyevd`).
38/// Guarantees orthonormal eigenvectors stored as columns of \f$V\f$ and sorted real eigenvalues \f$\Lambda\f$.
39///
40/// @param A Symmetric matrix carrying compile-time symmetry evidence (e.g. `num::assume_symmetric(A)`).
41/// @param tol Convergence tolerance on sum of squared off-diagonal elements \f$\sum_{i \ne j} A_{ij}^2\f$
42/// (used by the seq/omp Jacobi paths; ignored by the LAPACK path).
43/// @param max_sweeps Maximum number of cyclic Jacobi sweeps (default: 100; ignored by the LAPACK path).
44/// @return `eigen_result` containing sorted eigenvalues, column eigenvector matrix, sweep count, and convergence status.
45///
46/// Picks the best available implementation at compile time: LAPACK divide-and-conquer
47/// (`dsyevd`) if configured, else OpenMP Jacobi sweeps, else sequential Jacobi sweeps.
48/// To force a specific one, call `num::lapack::eig_sym`, `num::omp::eig_sym`, or
49/// `num::seq::eig_sym` directly.
50/// @see assume_symmetric, make_symmetric, lanczos, power_iteration
51eigen_result eig_sym(const linear::sym_mat<mat> &A, real tol = 1e-12, idx max_sweeps = 100);
