Detailed Description

Reusable sparse solver for (s I - A). With SuiteSparse enabled, the sparsity analysis is retained while numeric values are rebuilt per shift. Without SuiteSparse, factorize/solve report that no sparse complex backend is available rather than silently densifying a large matrix.
