Sample the equivalence-relation axioms a union-find claims to maintain.

find, unite and connected are an implementation of an equivalence relation, and the properties that make them correct are reflexivity, symmetry and transitivity of \(\sim\), plus agreement between connected(u,v) and \(\mathrm{find}(u) = \mathrm{find}(v)\). None of that is decidable from the type, so it is sampled here. Takes a mutable reference because path compression rewrites the forest while answering queries: find is observationally pure but not physically const.

Verify the defining structure of a graph Laplacian \(\Delta = D - W\).

A Laplacian is symmetric with zero row sums, which is exactly the statement \(\Delta \mathbf{1} = 0\): the constant vector lies in its null space. That null space is why a Laplacian is positive semi-definite and must be asserted law::psd rather than law::spd — asserting the latter claims an invertibility it does not have.

Accepts dense or CSR storage; for CSR only the stored entries are visited, so the check stays proportional to the number of non-zeros.
