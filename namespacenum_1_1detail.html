◆ build_block_order()

block_layout num::detail::build_block_order ( view< const idx >  levels)
inline

Compress arbitrary level labels into contiguous blocks and build the permutation.

Labels need not be contiguous, zero-based, or dense; they are sorted, and the distinct values become blocks 0, 1, ... in that order. Rows keep their original relative order within a block, so the permutation is deterministic and a run of already-sorted labels is the identity.

◆ check_params()

void num::detail::check_params ( const ode_params &  p,
const char *  method 
)
inline

Reject integration parameters that cannot produce a trajectory.

Every stepper advances by min(h, t1 - t) and stops once t reaches t1. Two parameter values break that silently rather than loudly: h = 0 advances time by nothing, so the loop never terminates; and tf < t0 satisfies the stop condition on the first call, so the integrator returns the initial condition and reports success. Backward integration is not supported — say so rather than appearing to do it.
