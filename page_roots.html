Root Finding

Bracketing and derivative-based solvers for scalar nonlinear equations \(f(x) = 0\).

1. Root Result (num::root_result)

struct root_result {
double root{0.0}; // Computed root x*
double residual{0.0}; // Residual |f(x*)|
idx iterations{0}; // Iteration count performed
bool converged{false};// True if |f(x*)| <= tol or bracket size <= tol
};

2. Solvers

Bisection Method (num::bisection)

Linear convergence on a bracketing interval \([a, b]\) with \(f(a) \cdot f(b) < 0\).

root_result bisection(scalar_fn f, double a, double b, double tol = 1e-8, idx max_iter = 100);
auto f = [](double x) { return std::cos(x) - x; };
num::root_result r = num::bisection(f, 0.0, 1.0, 1e-12);
