14/// @brief Function whose sign can be compared across an interval.

16/// \f[ f(a) \, f(b) < 0 \f]

18/// A sign change guarantees a root by the intermediate value theorem, which is
19/// what makes bisection and Brent's method unconditionally convergent. Whether a
20/// given \f$[a,b]\f$ brackets a root depends on the values, so it is checked by
21/// `num::roots::debug::verify_bracket`.

23concept bracketable_function = scalar_function<F, T> && std::totally_ordered<T>;
