Select a matrix multiplication kernel

There is nothing to select. num::matmul dispatches to the configured backend (num::blas, num::omp, num::cuda), and the portable num::kernel::gemm underneath it sizes its own register tile and cache panel from the target, so there is no block size or tile width for a caller to pass. Call a backend by name to pin one:

num::matmul(A, B, C); // Configured backend.
num::seq::matmul(A, B, C); // Portable kernel, single-threaded.
num::omp::matmul(A, B, C); // Threaded, same kernel per tile.
