Detailed Description

template<class Op, class Ax>
requires linear_operator<Op>
class num::operators::structured_op< Op, Ax >

A linear operator carrying an asserted axiom.

Replaces what was one hand-written wrapper class per property. The axiom is a template parameter, so the hierarchy supplies the implications and there are no per-property tag typedefs to keep in sync.
