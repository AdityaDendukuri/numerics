Detailed Description

template<typename Key = double, std::integral Index = num::idx, typename Compare = std::less<Key>>
class num::indexed_priority_queue< Key, Index, Compare >

Addressable priority queue where each item is identified by a unique index in [0, capacity).

Template Parameters
KeyThe priority key type (e.g. double, float, int).
IndexThe integer type for element indices (e.g. num::idx, uint32_t).
CompareComparator where comp(a, b) == true means a has higher priority (default std::less for min-heap).
