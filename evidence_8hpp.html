Detailed Description

Immutable evidence that a runtime value satisfies a law.

claims<T, L> (models.hpp) asks what a type asserts. This header is about what a particular value has been shown to satisfy, and by what means: assume<L>(x) records a caller's promise, require<L>(x) records an exhaustive check. Both carry an evidence_provenance naming the origin and the source location, so a later failure can be traced to the line that made the claim.
