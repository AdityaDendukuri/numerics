Detailed Description

template<class Op>
class num::chebyshev_preconditioner< Op >

Chebyshev polynomial preconditioner \(M^{-1} = p_m(A)\).

Applies degree operator applications per invocation and allocates nothing after construction. Holds a reference to the operator, which must outlive it.

Template Parameters
OpSelf-adjoint linear operator type.
