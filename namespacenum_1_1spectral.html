vec num::spectral::dst1 ( const vec &  x)
inline

Unnormalised DST-I of an N-point vector via complex FFT.

X[k] = sum_{j=1}^{N} x[j] * sin(j*k*pi/(N+1)), k = 1..N (stored 0-indexed). Odd-extension y = [0, x, 0, -rev(x)] has length M = 2(N+1). FFT(y)[k] = -2i * sum sin(...) => DST(x)[k-1] = -Im(FFT(y)[k]) / 2.

void num::spectral::dst_check_size ( int  N)
inline

Reject a length the odd-extension route cannot transform.

The extension has length 2(N+1), and the radix-2 FFT needs that to be a power of two, so N has to be one less than a power of two.

Compute unnormalized forward 1D Fast Fourier Transform \(X_k = \sum_{j=0}^{n-1} x_j e^{-2\pi i j k / n}\).

Dispatches to FFTW3 when linked or in-tree SIMD / sequential Cooley-Tukey Radix-2 / Bluestein kernel.

Parameters
inInput complex vector of length \(n\).
outOutput complex spectrum vector (must be sized to \(n\)).
bFFT backend tag (fft_backend::fftw, fft_backend::simd, fft_backend::seq).
See also
ifft, rfft, fft_plan
