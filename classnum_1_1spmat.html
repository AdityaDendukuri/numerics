Detailed Description

Sparse matrix in Compressed Sparse Row (CSR) format.

Non-zero values for row i are stored in vals_[row_ptr_[i] .. row_ptr_[i+1]). Corresponding column indices are in col_idx_[row_ptr_[i] .. row_ptr_[i+1]).

Examples
00_core_storage_and_helpers.cpp, and 02_iterative_krylov_solvers.cpp.

Build from zero-based compressed-column (CSC) arrays.

The returned matrix is stored in Numerics' native CSR format. The payload arrays may contain a trailing unused entry, as produced by the Armadillo sparse serializer; only the first col_ptrs.back() entries are consumed. All indices and pointers are zero-based.
