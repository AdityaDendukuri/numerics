Detailed Description

Value-returning dense arithmetic, and opt-in operators built on it.

Numerics' primary kernels write into caller-provided buffers so that no allocation happens inside a simulation loop. That remains the default. The functions here are the convenience tier above them: each returns its result and checks conformance, which the out-parameter forms cannot do because the caller has already sized the output.

Operators live in the nested num::ops namespace and are therefore opt-in. Ordinary lookup does not find them until a translation unit asks:

using namespace num::ops;
const vec r = y - Z * q;
num::basic_vec< real >
