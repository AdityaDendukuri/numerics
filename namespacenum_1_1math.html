◆ verify_law()

template<class L , class Obj , class V >
void num::math::verify_law ( const Obj &  object,
std::source_location  loc = std::source_location::current() 
)
inline

Verify L and every law it implies, weakest first.

The chain comes from L::base, so this is the only place the ordering is expressed. Adding a law between two existing ones makes every stronger law verify it with no edit to any verifier. This prevents the class of bug in which spd tested self-adjointness and definiteness but silently skipped semidefiniteness.

Template Parameters
LThe law to verify.
ObjThe object claiming it.
Vvec type the probes should draw from.
